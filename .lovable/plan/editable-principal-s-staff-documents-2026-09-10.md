# Editable Principal’s staff documents

## What will be added

- Add three new document makers under Principal’s Documents:
  - Administration
  - Heads of Departments
  - Class Teachers
- Pre-fill each document with the names and details shown in the supplied photographs.
- Keep every office, department, subject, class, and staff name editable before download.
- Allow rows to be added or removed so the documents can be maintained as staffing changes.
- Download each document as a polished A4 PDF with the school logo and the existing blue-and-gold colours.

## Document details

- Administration uses two columns: Office and Name.
- Heads of Departments uses three columns: Department, HOD, and Subjects. Subjects can be edited as a list.
- Class Teachers uses two columns: Class and Teacher.
- The handwritten corrections visible in the Class Teachers photograph will be used as the current values where legible.

## Technical section

- Add one reusable branded staff-list PDF generator, with safe page breaks and repeating table headers.
- Add editable row controls to the existing Principal’s Documents page using the current form and button components.
- Keep this change limited to Principal’s Documents; it will not alter timetable, class, teacher, or subject records.
- Verify TypeScript and generate sample PDFs for visual inspection of layout, wrapping, logo, and colours.
